# ART RESEARCH STUDIO

A private, bilingual art research studio. Phase 1 establishes the editorial front-end and navigation.

## Local development
Requires Node.js 20+.

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Roadmap
- Phase 1: responsive bilingual homepage and research areas.
- Phase 2: private authentication, database, artist/paper records and reading notes.
- Phase 3: daily research discovery, source verification and scheduled publishing.

The current homepage is a front-end prototype. It does not yet fetch live papers, save notes or run scheduled updates.
